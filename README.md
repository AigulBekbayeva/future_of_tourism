# The Future of Tourism — геопортал

Три интерактивные карты на одной странице для челленджа **The Future of Tourism**. Слева — описание выбранной карты, переключатели, легенда и рейтинги; справа — карта (глобус или плоская проекция). Весь интерфейс на английском.

| № | Карта | Что показывает |
|---|---|---|
| 01 | **Where Does Climate Attract Tourists Today?** | География климатической комфортности: сколько дней в году погода подходит для отдыха, по 3 627 регионам мира (первый административный уровень) |
| 02 | **Will Our Favourite Destinations Become Too Hot?** | Изменение климатической пригодности: сколько комфортных дней регион потеряет или получит и сколько станет дней с тепловым стрессом, по трём сценариям выбросов и двум периодам |
| 03 | **Which Economies Depend on Climate-Sensitive Tourism?** | Население и экономика стран, зависящих от туризма: доля доходов от иностранных туристов в ВВП и экспорте, население (кружки) и бивариантная карта «зависимость × изменение климата» |


## Структура

```
index.html            разметка и окно «About & method»
css/style.css         стили (панель слева, карта справа, мобильная вёрстка)
js/app.js             логика: загрузка данных, раскраска, легенды, подсказки, карточки регионов
lib/                  MapLibre GL JS 5.24 и topojson-client (локальные копии, без CDN)
data/
  climate.json        показатели климатической комфортности по регионам (≈3,9 МБ)
  regions.topo.json   границы регионов GADM 3.6, упрощённые (≈1,5 МБ)
  countries.topo.json границы стран Natural Earth 1:50m
  economy.json        туризм, население, ВВП и агрегированный климат по странам
scripts/              полный конвейер подготовки данных (run.sh + Python)
```

Внешних запросов страница не делает: подложка не используется, все библиотеки и данные лежат в репозитории.


## Методика

### Климатическая комфортность (карты 01–02)

- **Погода сейчас.** Суточные значения температуры, относительной влажности и осадков за 2020–2025 гг. из реанализа ERA5, осреднённые по регионам GADM 3.6 (проект AREAdata). Для 17 малых территорий без регионов используются значения по стране.
- **Коррекция температуры.** В AREAdata температура взята с уровня 1000 гПа, что завышает её в горах (например, в Непале на ~10 °C). Ряд каждого региона сдвинут так, чтобы среднее совпало с приземным климатом WorldClim 2.1 на 2021–2040 гг. (SSP2-4.5, медиана моделей). Суточная изменчивость сохраняется.
- **Комфортный день:** осадки ≤ 5 мм, нет теплового стресса и среднесуточная температура
  - 15–24 °C — профиль *Sightseeing & city* (экскурсии, города, походы);
  - 23–30 °C — профиль *Beach & sun* (пляжный отдых).
  Диапазоны соответствуют оптимальным значениям Holiday Climate Index (Scott et al., 2016), пересчитанным с дневного максимума на среднесуточную температуру.
- **День теплового стресса:** среднесуточный humidex ≥ 42 (днём — зона «сильного дискомфорта / опасно»).
- **Будущее.** Потепление каждого региона между 2021–2040 и 2041–2060 / 2081–2100 гг. по даунскейлингу CMIP6 WorldClim 2.1 (до 9 моделей) прибавляется к каждому дню 2020–2025 гг. (метод дельт). На карте показана медиана по моделям, в карточке региона — разброс. Влажность и осадки остаются на сегодняшнем уровне.

### Экономика туризма (карта 03)

- **Доходы от международного туризма, % экспорта** — World Bank WDI `ST.INT.RCPT.XP.ZS`, последнее значение за 2015–2019 гг. (до пандемии; ряд Всемирного банка заканчивается 2020 г.).
- **Доходы от туризма, % ВВП** = доля в экспорте × экспорт товаров и услуг в % ВВП (`NE.EXP.GNFS.ZS`) за тот же год. Это оценка поступлений от иностранных туристов; внутренний туризм и косвенный эффект не учтены (в отличие от оценок WTTC).
- **Население** — `SP.POP.TOTL`, последний год; **ВВП** — `NY.GDP.MKTP.CD`, `NY.GDP.PCAP.CD`.
- **Изменение климата для страны** — изменение числа комфортных дней (любой профиль), средневзвешенное по населению регионов (плотность населения GPWv4 × площадь).
- **Бивариантные классы:** зависимость < 3 % / 3–10 % / ≥ 10 % ВВП × изменение комфортных дней: рост > 5 / почти без изменений / потеря > 5 дней.

### Ограничения

- Значения осреднены по регионам: в больших регионах побережье и горы сливаются.
- Не учтены солнечное сияние, ветер и температура воды; влажность и осадки не прогнозируются.
- Шесть лет наблюдений — короткий базовый период.
- Возле пороговых значений небольшое потепление может изменить сразу много дней (особенно во влажных тропиках).
- Карта описывает климатическую пригодность, а не реальный туристический спрос.

## Источники данных

| Данные | Источник | Лицензия |
|---|---|---|
| Суточный климат по регионам, 2020–2025 | AREAdata (Pearse Lab) на основе ERA5, Copernicus C3S — github.com/pearselab/areadata | GPL-3.0 (AREAdata), Copernicus licence (ERA5) |
| Прогнозы CMIP6 | WorldClim 2.1 future climate (Fick & Hijmans, 2017), агрегировано AREAdata | бесплатно для некоммерческого использования |
| Туризм, экспорт, население, ВВП | World Bank WDI, зеркало github.com/datasets/world-development-indicators | CC BY 4.0 |
| Границы регионов | GADM 3.6 | только некоммерческое использование, распространение — с разрешения GADM |
| Границы стран | Natural Earth 1:50m | public domain |
| Библиотеки | MapLibre GL JS (BSD-3-Clause), topojson-client (ISC) | |

> ⚠️ Лицензия GADM запрещает распространение данных без разрешения. Для некоммерческого челленджа это обычно не вызывает проблем, но, если репозиторий публичный, имеет смысл указать GADM как источник (это уже сделано) или запросить разрешение.

## Как пересобрать данные

```bash
pip install pandas numpy pyreadr dbfread
cd scripts
./run.sh        # скачает исходники (~150 МБ) в scripts/raw, пересчитает показатели и запишет ../data/*.json
```

Основные параметры (диапазоны температур, порог осадков, порог humidex, сценарии) заданы в начале `scripts/compute.py`.
